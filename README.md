# Telegram login, registration and notifications for Flarum

Telegram authentication and notification delivery for Flarum 1.8.x. This package is a maintained fork of `nodeloc/telegram`, originally rewritten from the Flagrow Telegram extension.

## Features

- Log in with Telegram.
- Register with Telegram from the Flarum sign-up modal.
- Link an existing Flarum account to Telegram.
- Send Flarum notifications through Telegram when enabled by the administrator and the user.
- Compatible with Flarum 1.8.14+ and PHP 8.1-8.3.

## Installation

```bash
composer require nodeloc/telegram
php flarum migrate
php flarum cache:clear
```

## Updating

```bash
composer update nodeloc/telegram -W
php flarum migrate
php flarum cache:clear
php flarum assets:publish
php flarum cache:clear
```

## Configuration

1. Create a Telegram bot with [BotFather](https://t.me/BotFather).
2. Configure the bot domain in BotFather. The domain must match the public domain of your forum, for example `example.com` without `https://` and without a path.
3. Open the Flarum admin panel and enable the Telegram extension.
4. Enter the bot username without the `@` symbol.
5. Enter the bot token generated by BotFather for the same bot.
6. Enable notifications only if you want Telegram to appear as a notification delivery method in user settings.

## Login and Registration Flow

The extension adds a Telegram button to both Flarum authentication modals:

- Login modal: after the standard Flarum login button and before the modal footer.
- Sign-up modal: after the standard Flarum registration button and before the modal footer.

Telegram returns the user to `/auth/telegram`. Flarum then completes the authentication flow, creates or links the account when needed, and redirects the user back to the forum.

## Notifications

When notifications are enabled, users can link Telegram and select Telegram as a notification method in their notification settings. If the bot is blocked or not authorized by the user, the extension stores that state and shows a warning in the user's settings page.

## Troubleshooting

### Bot domain invalid

Check the bot domain in BotFather. It must be the forum domain only, without protocol, path, port, or trailing slash. Also check that the bot username and bot token in the extension settings belong to the same bot.

### Changes are not visible after update

Clear and republish Flarum assets:

```bash
php flarum cache:clear
php flarum assets:publish
php flarum cache:clear
```

If the old JavaScript is still cached, remove old forum assets and publish again:

```bash
rm public/assets/forum*.js 2>/dev/null
php flarum cache:clear
php flarum assets:publish
php flarum cache:clear
```

## Security

If you discover a security vulnerability, report it with as many details as possible, including the output of `php flarum info`.

# Вхід, реєстрація та сповіщення Telegram для Flarum

Розширення додає авторизацію, реєстрацію та доставку сповіщень через Telegram для Flarum 1.8.x. Це підтримуваний форк `nodeloc/telegram`, який походить від переписаного розширення Flagrow Telegram.

## Можливості

- Вхід через Telegram.
- Реєстрація через Telegram у стандартному вікні реєстрації Flarum.
- Прив'язка Telegram до вже існуючого облікового запису Flarum.
- Доставка сповіщень Flarum через Telegram, якщо це увімкнено адміністратором і користувачем.
- Сумісність із Flarum 1.8.14+ та PHP 8.1-8.3.

## Встановлення

```bash
composer require nodeloc/telegram
php flarum migrate
php flarum cache:clear
```

## Оновлення

```bash
composer update nodeloc/telegram -W
php flarum migrate
php flarum cache:clear
php flarum assets:publish
php flarum cache:clear
```

## Налаштування

1. Створіть Telegram-бота через [BotFather](https://t.me/BotFather).
2. Налаштуйте домен бота в BotFather. Домен має збігатися з публічним доменом форуму, наприклад `example.com`, без `https://` і без шляху.
3. Відкрийте адмін-панель Flarum і увімкніть розширення Telegram.
4. Вкажіть ім'я бота без символу `@`.
5. Вкажіть токен, створений у BotFather для цього самого бота.
6. Вмикайте сповіщення лише тоді, коли потрібно додати Telegram як спосіб доставки сповіщень у налаштуваннях користувача.

## Вхід і реєстрація

Розширення додає кнопку Telegram у два стандартні вікна Flarum:

- Вікно входу: після стандартної кнопки входу Flarum і перед нижнім блоком вікна.
- Вікно реєстрації: після стандартної кнопки реєстрації Flarum і перед нижнім блоком вікна.

Telegram повертає користувача на `/auth/telegram`. Після цього Flarum завершує авторизацію, створює або прив'язує обліковий запис за потреби та повертає користувача на форум.

## Сповіщення

Якщо сповіщення увімкнено, користувач може прив'язати Telegram і вибрати Telegram як спосіб доставки сповіщень у своїх налаштуваннях. Якщо бот заблокований або користувач не авторизував бота, розширення зберігає цей стан і показує попередження в налаштуваннях користувача.

## Вирішення проблем

### Bot domain invalid

Перевірте домен бота в BotFather. Має бути вказаний тільки домен форуму, без протоколу, шляху, порту або слеша в кінці. Також перевірте, що ім'я бота й токен у налаштуваннях розширення належать одному й тому самому боту.

### Зміни не видно після оновлення

Очистіть кеш і перевидайте assets Flarum:

```bash
php flarum cache:clear
php flarum assets:publish
php flarum cache:clear
```

Якщо старий JavaScript усе ще кешується, видаліть старі forum assets і опублікуйте їх повторно:

```bash
rm public/assets/forum*.js 2>/dev/null
php flarum cache:clear
php flarum assets:publish
php flarum cache:clear
```
